Gold-bordered call-to-action button used for RSVP and website navigation actions.

```jsx
<Button variant="primary" size="md" onClick={handleSubmit}>RSVP</Button>
```

Variants: `primary` (solid gold fill), `secondary` (gold outline), `ghost` (text-only, for tertiary links). Sizes: `sm`, `md`, `lg`. `disabled` dims to 50% opacity.
