# Invitation Suite

Save-the-date, formal invitation, and RSVP card — cosmetic recreations of the couple's printed invitation, rebuilt with design-system tokens.

Files: `SaveTheDate.jsx`, `Invitation.jsx`, `RSVPCard.jsx` (plain React, loaded via `<script type="text/babel" src="...">` in `index.html`, each exposes itself on `window`).
